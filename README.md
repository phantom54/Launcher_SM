A simple C++ launcher with couple fixes for a unity game called Seaside Mystery.

Supports all versions from v0.30.0 to v0.39.1 and above: uses fallback autoscan mechanism if no known versions found.

Release ships with optional Cheat Engine version which work like auto-attacher (not as a launcher) so it can be attached mid-game. Also you can run Launcher with `-a` parameter to make it work like Cheat Engine version

Building:

Download Visual Studio Community https://visualstudio.microsoft.com/downloads/

Choose Classic Desktop C++

When installation finishes open `Launcher.sln` and hit `F7` or click build solution
